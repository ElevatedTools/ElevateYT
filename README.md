# ElevateYT

A desktop app for YouTube Music on Windows. Same YouTube Music you know, with a few things the browser tab never had.

**[Download the latest version](https://github.com/ElevatedTools/ElevateYT/releases/latest)**: grab the `.exe` and run it.

## What you get

- **Discord status**: your friends see what you're listening to, with the cover art and time left. Turn it off any time in Settings.
- **Synced lyrics**: open the Lyrics tab and the words follow along with the song. If they're a bit early or late, nudge them with the − / + buttons.
- **A cleaner player bar**: a bigger, easier bar at the bottom. Drag it up, double-click it or hit the arrow to open the player.
- **Media keys**: play, pause and skip from your keyboard or the Windows media popup, even when the app is in the background.
- **Lives in the tray**: closing the window keeps the music playing. You can also have it start with Windows.
- **Updates itself**: it checks for new versions on its own and asks before installing, so an update never cuts off a song.
- **Light on your PC**: it's built on the browser engine that's already part of Windows, so it starts fast and doesn't eat your memory.

## Shortcuts

| Key | What it does |
|---|---|
| `F11` | Full screen |
| `Ctrl` + `,` | Settings |
| `Alt` + `←` / `→` | Back / forward |

## "Windows protected your PC"

You might see this the first time you run the installer. It shows up for apps from smaller developers that Windows hasn't seen much yet. Click **More info**, then **Run anyway**.

## Signing in

Sign in with your Google account like you would on the website. Your playlists, likes and library are all there. ElevateYT never sees your password; sign-in happens on Google's own page.
